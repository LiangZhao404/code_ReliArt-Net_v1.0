Code availability

The MATLAB R2025b (Version 25.2) implementation of ReliArt-Net used to document and reproduce the manuscript-described computational workflow is publicly available at https://github.com/LiangZhao404/code_ReliArt-Net_v1.0. The repository includes preprocessing, the multi-branch CNN and Transformer architecture, adaptive fusion, dual-output training, post-hoc temperature scaling, inference, and evaluation utilities. Numerical settings explicitly reported in the manuscript are documented in the repository; implementation values that are not numerically specified in the manuscript are identified separately as repository defaults. The artwork images are not redistributed with the code and remain subject to the terms of their source institutions and repositories.
